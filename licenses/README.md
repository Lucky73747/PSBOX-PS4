# Retained notices

This directory preserves exact full license/notice texts for vendored components, fonts, technical references and selected external SDK components. Original notices also remain in source trees.

`external/sdk/` is copied from the development SDK's notice directory, including its checksums. `external/Orbis-SDK-NOTICE.md` describes component-specific and unresolved licensing. Its original relative references describe the external SDK layout, not files promised in this source export. Including notices does not redistribute the SDK itself, certify all of its terms or supply missing corresponding source. The full SDK and external build archives are deliberately excluded.

`references/Greenlight-MIT.txt` preserves Greenlight's notice conservatively; it is not a claim that the whole Greenlight player is included. Source origins are explained in [../docs/SOURCE-PROVENANCE.md](../docs/SOURCE-PROVENANCE.md).

The PS4 CMake recipe copies this collection into **new** packages. Previously produced PKGs do not change. See [../docs/LICENSE-STATUS.md](../docs/LICENSE-STATUS.md) before distributing binaries.
