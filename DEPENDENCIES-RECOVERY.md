# Restoring a development environment

Install the tools and external inputs described in [BUILD-PREREQUISITES.md](BUILD-PREREQUISITES.md) and [DEPENDENCIES.md](DEPENDENCIES.md). Set environment variables to your own input locations, then run `tools/ps4/build.sh --check-inputs`.

The PS4 SDK and related platform build products are not distributed with this source. Obtain them from authorized sources and verify their identities and terms before use. Never add account data, credentials, console logs, or generated packages to a source export.
